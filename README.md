# Aryan Patel — Portfolio

Personal portfolio built with Next.js, TypeScript, and CSS Modules.

## Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** CSS Modules
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.
